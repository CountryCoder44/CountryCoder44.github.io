  • React
  • Node.js

An AI-native, full-stack coding education platform: structured lessons, practice assignments graded by actually running the learner’s code in a sandboxed multi-language execution service, and an AI tutor named Trak. Automated Aeroponics

  • C++
  • Arduino
  • Embedded systems
  • Web app

Built while I was self-taught at Microgreens & Micromachines. Arduino controllers in C++ run nutrient delivery, misting, and environmental controls from sensor-driven logic, making the operation about 80% automated. A web app I built monitors it remotely with real-time telemetry and email and text alerts. The system reached roughly six times the crop yield in the same footprint.

Mobile Reporting App

  • Mobile
  • Workflow automation
  • Client project

For a logistics and operations client, I designed and deployed a mobile app that tracks employee locations during work hours to fill in Interstate Fuel Tax Agreement (IFTA) reports automatically. It improved reporting accuracy by 27%, and together with related workflow automation it removed more than 30 hours of manual work per week.

Client work. Source is not public.
