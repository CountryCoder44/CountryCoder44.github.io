TrakCode

An AI-native coding education platform I designed and built. Learners work through ordered lessons, solve practice assignments graded by running their code, and can ask an AI tutor named Trak for help.

It has a React and TypeScript front end, a Node.js, Express, and TypeScript API backed by MongoDB, and a separate execution service that compiles and runs learner code in Python, Java, C++, and TypeScript. I used this one real system for all three enhancement categories, so every change had to hold up in software people actually use.
